# BT-Net

BT-Net is a parameter-efficient Transformer for three-channel-guided
hyperspectral image fusion. A Transformer encoder--decoder models global
spatial context, and a Gated Latent State Bridge (GLSB) combines local
one-dimensional mixing, gated modulation, and cumulative state updates over
jointly embedded latent channels. These latent channels are learned features;
they are not physical wavelength bands.

## Repository contents

- `main.py`: 200-epoch training, validation, and testing entry point.
- `model.py`: BT-Net, Transformer components, and GLSB.
- `data.py`: HDF5 dataset loader.
- `eval_metrics.py`: full-image PSNR, SAM, CC, ERGAS, and SSIM evaluation.
- `measure_inference_time.py`: patch-inference timing.
- `datasets/split_config.py`: local dataset paths only.
- `checkpoints/bt_net_epoch_200.pth`: CAVE epoch-200 checkpoint.

The original datasets and generated HDF5 files are not redistributed. Download
the source data from their providers and place locally generated files under
`datasets/`.

pip install -r requirements.txt

## Source datasets

- [CAVE multispectral image database](https://cave.cs.columbia.edu/repository/Multispectral/)
- [Harvard hyperspectral image database](https://vision.seas.harvard.edu/hyperspec/)
- [Chikusei hyperspectral dataset](http://park.itc.u-tokyo.ac.jp/sal/hyperdata/)

## HDF5 layout

Each file must provide the following datasets in channel-first format:

- `GT`: high-resolution hyperspectral ground truth, `[N, C, H, W]`;
- `LRHSI`: fourfold-downsampled hyperspectral input, `[N, C, H/4, W/4]`;
- `HRMSI` or `RGB`: high-resolution three-channel guide, `[N, 3, H, W]`.

All arrays are normalized to `[0, 1]`. The LR-HSI is generated by fourfold
bicubic downsampling. The high-resolution RGB guide is synthesized from the
reference HSI with a row-normalized three-channel spectral response matrix,
`RGB[c] = sum_b SRF[c, b] * GT[b]`; it is not formed by directly selecting
three bands. CAVE and Harvard use their dataset-specific 31-band response
profiles. For 128-band Chikusei, the RGB channels use Gaussian responses
centered at 660, 530, and 470 nm, respectively, with `sigma = 15 nm`.

The experiments use the following evaluation units:

- CAVE: 11 complete `512 x 512 x 31` test scenes;
- Harvard: 10 complete `512 x 512 x 31` centre-cropped scenes;
- Chikusei: six spatially disjoint `640 x 640 x 128` test regions.

For Chikusei region-level evaluation, the recommended file is
`datasets/chikusei_test_6areas_640.h5`, with `GT.shape == (6, 128, 640, 640)`.
A flat file containing 2400 anonymous `64 x 64` patches cannot reproduce the
six-region statistics because it does not retain region identifiers and patch
coordinates.

## Training

The configuration in `main.py` matches the manuscript: seed 1, batch size 1,
Adam with learning rate `2e-4`, mean L1 loss, no mixed precision, and 200
epochs. The switches near the bottom
of `main.py` control training, testing, and checkpoint resumption:

```python
train_or_not = 1
test_or_not = 0
resume_or_not = 0
```

Run:

```bash
python main.py
```

## Full-image evaluation

Large scenes are inferred using non-overlapping `64 x 64` patches to avoid the
memory cost of full-scene attention. Boundary patches are padded when needed,
predictions are cropped to their valid extent, and all patches are written back
to a complete prediction cube. Metrics are calculated once per reconstructed
image/region and then averaged across images; patches are not treated as
independent metric samples.

```bash
python eval_metrics.py \
  --ckpt checkpoints/bt_net_epoch_200.pth \
  --val datasets/test_dataset.h5
```

The script reports PSNR, SAM (degrees), CC, ERGAS (scale factor 4), and SSIM.
PSNR uses one global MSE over all bands and pixels of each complete cube.

## Checkpoint compatibility

The public epoch-200 checkpoint was produced before the bridge was renamed to
GLSB. `BTNet.load_state_dict` transparently maps its legacy bridge parameter
keys to the current `glsb_blocks` names; the checkpoint tensor values and file
format are unchanged.

## Inference time

Edit the local dataset paths in `measure_inference_time.py` if necessary, then
run:

```bash
python measure_inference_time.py \
  --ckpt checkpoints/bt_net_epoch_200.pth
```

GPU-forward time, wall-clock inference time, and per-patch time are reported
separately.
